# Industrial Blue Command Theme

The persisted `windows-blue` theme preset has been redesigned as the **Industrial Blue Command** palette. It uses a near-black navy command shell, electric-cyan interface signals, teal active states, and indigo logic emphasis while retaining the existing Windows Blue preference key for player compatibility.

| Interface role | Applied palette |
|---|---|
| Main background | `#000000` with `#020d1c` and `#061c1c` depth gradients |
| Shell and navigation | Near-black translucent shell, `#061c1c` to `#071e36` navigation gradient |
| Headers | `#021414` → `#0c2f2f` → `#0b345a` |
| Content panels | `#092b4b` → `#071d35` |
| Borders | `#185b88` main border and `#197ca9` active border |
| Primary UI accent | `#28bde7`, `#2baed6`, `#55d7ff`, `#62d8ff`, `#6ce5ff` |
| Feature-active accent | `#42d3c5` teal |
| Logic/status accent | `#8a9dff` indigo |
| Primary and secondary text | `#ffffff` / `#e7f8ff`, with `#b7dff0`, `#b9e6f5`, and `#9bcbe5` supporting text |

## Verification

Authenticated browser checks confirmed that the industrial palette appears on both the **Strategic Command** hub and the shared **Settings** shell. The compact three-group Stargate navigation remains visible and readable, shared command cards use dark navy panel treatment, live controls remain available, and the heading contrast issue was corrected after visual inspection.
