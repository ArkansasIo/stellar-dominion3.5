# OGame-Style Resource Header

The shared shell now renders turns and all economy counters inside one compact, continuous top-header bar. The former independent rounded resource cards were replaced by narrow adjacent cells with consistent dividers, labels, icons, tabular values, and a horizontal overflow path on constrained screens.

The unified bar contains Turns and Total, Metal, Crystal, Deuterium, Energy, Credits, Naquadah with live strategic per-turn income, Food, and Water. It retains the Industrial Blue command-center palette: near-black base, cyan separators and labels, an indigo turns segment, and distinct resource accent colors.

The live Stargate Command page was checked after the production rebuild. It displayed the entire counter set in a single uninterrupted header row, including 156,600 Naquadah and the live +11,200-per-turn strategic income rate. The server health endpoint remained healthy with a score of 100.
